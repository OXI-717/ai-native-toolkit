# Правило: спроси память до того, как строить гипотезу

Память агентов (`oxi-memory`) содержит уроки, которые уже стоили нам часов: «пайплайн
исполняет старый код из plugin-кэша», «TLS-флаппинг сети = PIA split-tunnel», «git push
виснет на macOS keychain». Она отвечает за ~0.6 с и **молчит, когда релевантного нет**
(порог similarity), поэтому лишний вызов ничего не стоит, а пропущенный — стоит часа.

## Когда спрашивать обязательно

**Перед разбором инцидента.** Упал пайплайн, зависла сессия, команда ведёт себя
необъяснимо, тест падает «непонятно почему» — первый шаг **до** построения гипотезы:

```bash
oxi-memory ask "<симптом своими словами>" -k 3
```

Симптом, а не диагноз: «gh падает с EOF, git рвётся на SSL_ERROR_SYSCALL», а не
«проблема с сетью». Диагноз — это уже гипотеза, а её мы и хотим проверить памятью.

**Перед вердиктом ревью.** Спроси память про **класс изменения** (не про заголовок PR):
«subprocess без таймаута», «guard пайплайна», «новый статус», «парсинг чужого JSON».
Урок, который вернётся, — это чеклист-пункт: PR, повторяющий записанную ошибку, — FAIL
со ссылкой на урок. Этот шаг уже вшит в промпт ревьюера (`prompts/review_pr.md`).

## Чего от правила НЕ требуется

- Не спрашивать память на каждый чих: тривиальная правка доков, переименование
  переменной, ответ на прямой вопрос по коду перед глазами.
- Не переформулировать запрос, если память промолчала. Тишина — это ответ «не знаю»,
  а не «спроси иначе». Порог настроен так, что на мусорных запросах ложных срабатываний
  нет (проверено: 0/5).

## Почему правило вообще нужно

Замер 2026-07-14: за восемь дней `ask` вызывалась в **одной сессии в день из ~90** — и
только там, где темой разговора была сама память. Причина была не в лени агентов, а в
том, что память искала не в том хранилище, отвечала по 10-21 с и ранжировала по числу,
не отражающему релевантность. Это починено (hit@8 = 10/10 на живых вопросах, 0.6 с), и
теперь узкое место — привычка: агент, которому знание не подмешали, за ним не идёт.
Подмешка закрывает пассивный сценарий; это правило закрывает активный — когда агент
сам должен пойти и спросить.
