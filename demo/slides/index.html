Проблема не в AI

Проблема в отсутствии процесса


AI-модели становятся лучше каждый месяц.

Но без контекста, правил и верификации — результат непредсказуем.


Как мы строим мосты: не «нарисуй мост», а
чертежи → материалы → проверка → сдача

AGENTS.md — онбординг-документ для AI-агентов.

Один файл в корне проекта = постоянная память.

[9:00 — 2 мин] «Представьте: к вам в команду каждый день приходит новый джун. Каждый раз заново объясняете: где тесты, какой стек, какие правила, что нельзя трогать. PHASE 3: FIX → TEST → RE-REVIEW
Автофикс → сборка → тесты → повторный review (до 3 итераций)
[18:00 — 3 мин] Показать на каждый блок. «Phase 1: запускаем 5 Sonnet-агентов параллельно через TeamCreate. Только ≥80 попадают в финальный отчёт. Phase 3: автоматический fix — AI правит код, запускает тесты, и если тесты проходят — делает повторный review. До 3 итераций.»

Зачем мульти-агентность?


Один агент5 параллельных агентов
Один ракурс5 специализаций
Усталость модели на длинном контекстеКаждый видит свой кусок
Нет перепроверкиHaiku-скореры верифицируют
~60% покрытие~95% покрытие
[21:00 — 2 мин] «Почему не один агент? Три причины. Первое — специализация. Security-сканер знает OWASP top 10, а code-reviewer знает паттерны кода. Разные навыки. Второе — изоляция контекста. Один агент на длинном контексте устаёт — начинает пропускать. У каждого агента свой чистый контекст. Третье — перекрёстная проверка. Haiku-скореры — это как second opinion. Дешёвая модель перепроверяет дорогую. Результат: 60% покрытие одним агентом vs 95% покрытие пятью.»

Принципы AI-Native Engineering


📄 Контекст — это код. AGENTS.md коммитится в git, ревьюится в PR.

🔍 AI проверяет AI. Один агент пишет, другие ревьюят.

📊 Confidence > opinion. Числовая оценка вместо субъективного мнения.

🔄 Fix loop. Review → Fix → Test → Re-Review — до чистоты.

🏗️ Инфраструктура масштабируется. Правила один раз, применяются в каждой сессии.

Итого


1. Контекст — AGENTS.md в каждый проект

2. Правила — rules/ коммитятся, не объясняются устно

3. Верификация — мульти-агентный review перед каждым PR

4. Измеримость — confidence scoring, не «мне кажется»


AI не заменяет инженера. AI меняет что значит быть инженером.
