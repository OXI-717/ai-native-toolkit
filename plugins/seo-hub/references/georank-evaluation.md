# ГЕОранк (`georank.ru`) как read-only источник GEO-данных — оценка #2901

**Проверено 2026-09-28 (UTC).** Объект оценки — российский ГЕОранк на
`georank.ru`, а не одноимённые сервисы на других доменах. Ниже «заявлено»
означает текст владельца продукта на публичном сайте, **не** проверку работы
личного кабинета или содержимого реальной выгрузки. Публикационная дата
страниц не указана; дата в таблицах — дата нашего просмотра. Платные измерения,
регистрация, запросы к закрытому API и обращение к поставщику не проводились.

**Граница Яндекса.** У ГЕОранк назван именно **ЯндексGPT**
([FAQ ГЕОранк](https://georank.ru/), просмотр 2026-09-28). Это нельзя
приравнять к измерению ответа **Алисы AI в Поиске** или исторической поверхности
**Нейро**: Яндекс описывает Алису AI в поисковой выдаче как отдельный
пользовательский сценарий с ответом над результатами и ссылками на источники
([справка Яндекса, просмотр 2026-09-28](https://yandex.ru/support/search/ru/alice));
при запуске Нейро Яндекс описывал объединение результатов Поиска и модели
YandexGPT 3 ([сообщение Яндекса от 2024-04-16](https://www.yandex.ru/company/news/01-16-04-2024)).
Следовательно, покрытие Алисы AI в Поиске и Нейро **не подтверждено**
перечнем моделей ГЕОранк.

## Контракт получения данных: что осталось неизвестным

На [публичной странице продукта](https://georank.ru/) (просмотр 2026-09-28)
есть фраза «Готово к интеграции», но рядом нет метода, схемы ответа или ссылки
на API. Ссылка сайта «Инструкция по установке и эксплуатации» ведёт на
[`https://lk.georank.ru/docs/manual.pdf`](https://lk.georank.ru/docs/manual.pdf).
При read-only запросе `HEAD` 2026-09-28 этот URL отвечал `200` с
`Content-Type: text/html;charset=UTF-8`; `GET` возвращал HTML оболочку
приложения (`<!doctype html>`), а не PDF. Этот результат ограничен публичным
неавторизованным доступом: он не доказывает, что документации нет у клиентов.

| Требуемое для #2901 | Статус на 2026-09-28 |
|---|---|
| Read-only API, методы, версия, схема, документация | **Неизвестно**. Маркетинговая фраза об интеграции и HTML по ссылке на инструкцию не устанавливают API-контракт. |
| Аутентификация API, роли и права чтения | **Неизвестно**. Логин/пароль подтверждены только для интерфейса входа; API-token/OAuth, область доступа и запрет на запуск измерений не подтверждены. |
| CSV/JSON/Excel экспорт, ручная выгрузка и её тариф | **Неизвестно**. Обещанный отчёт после заявки не задаёт формат, доступность выгрузки или право повторного импорта. |
| Построчные поля | **Неизвестно**: исходный промпт и его ID, исполнение, текст ответа/цитата, упоминания, тональность, URL/домены цитат, модель, поверхность, регион/язык, момент измерения и окно. Аналитика на сайте не доказывает наличие этих полей в выгрузке. |
| Лимиты интеграции | **Неизвестно**: API rate limit, пагинация, объём истории, частота обновления и тарификация доступа. Продуктовые квоты 2 000/10 000 запросов в месяц не подменяют их. |
| Фактическое покрытие | **Неизвестно** по конкретным моделям и тарифам, городам/странам и по Алисе AI/Нейро в Поиске. Нет проверенного ответа или датасета для теста качества. |

## Вердикт для `seo-hub`

**Выбор `adapter` / `manual-import` / `reject` пока не подтверждён.** Для
`adapter` требуется документированный read-only API или реальный ответ со
схемой полей. Для `manual-import` требуется подтверждённая выгрузка и её
формат. Основания для `reject` как утверждения о непригодности продукта также
нет: отсутствие публичного контракта не доказывает отсутствие закрытого API
или экспорта. Текущий практический исход — **не подключать ГЕОранк как источник
данных** до появления первичного контракта; это решение о доказанности
интеграции, а не оценка качества самого сервиса. Предварительное
`manual-import` из комментария к #2901 от 2026-09-15
не повышается до финального вердикта без подтверждения выгрузки.

Существующий [контракт импортера `ai_visibility_import`](../../seo-observer/references/ai-visibility-import.md)
задаёт целевые измерения
`mention`/`citation`, `cohort`, `surface`, `model`, `locale`, `window`.
Это **контракты нашего кода**, не схема ГЕОранк; маппинг полей поставщика
сейчас был бы выдумкой. Последующие #2902 (тональность) и #2904 (РФ-поверхности)
не должны считать маркетинговые заявления доказанным покрытием или источником
построчных данных. Проверка закрытых условий и реального экспорта остаётся
внешней зависимостью при отдельном разрешении на неё.
