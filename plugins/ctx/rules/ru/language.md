# Правило: язык

Отвечай на русском языке. Технические термины можно оставлять по-английски, если они общеупотребимы (API, endpoint, commit, PR, merge, deploy и т.п.).

Комментарии в коде — на языке проекта (смотри существующий код).

Сообщения коммитов — следуй конвенции проекта (смотри `git log`).
