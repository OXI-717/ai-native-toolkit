# Правило: формат дат

- В именах файлов и frontmatter: ISO `YYYY-MM-DD` (например `2026-04-12`).
- В frontmatter с временем: `YYYY-MM-DD HH:MM` (например `2026-04-12 19:00`).
- В тексте markdown для людей: длинный формат допустим (`12 апреля 2026`), но ISO предпочтительнее.
- Не используй американский `MM/DD/YYYY` — он неоднозначен.
