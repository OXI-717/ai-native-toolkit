# Правило: конфиденциальность в публичных материалах

При генерации любого **публичного** контента (резюме, LinkedIn-посты, кейс-стади, портфолио, статьи, контент для каналов):

- **Никогда** не упоминать реальные названия рабочих проектов и компаний-клиентов — заменять обобщённым описанием (домен, масштаб, стек).
- **Никогда** не упоминать имена людей из рабочих проектов — коллеги, клиенты, партнёры.
- Не включать конкретные детали, позволяющие идентифицировать проект или компанию.
- Допускается упоминать только свои личные open-source проекты и публичные профили.
