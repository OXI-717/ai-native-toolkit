# Rule: date format

- In file names and frontmatter: ISO `YYYY-MM-DD` (e.g. `2026-04-12`).
- In frontmatter with time: `YYYY-MM-DD HH:MM` (e.g. `2026-04-12 19:00`).
- In markdown body for humans: long format is acceptable (`April 12, 2026`), but ISO is preferred.
- Do not use American `MM/DD/YYYY` — it is ambiguous.
