# context-runbooks

Runbooks for building a personal or team agent-working structure.

The plugin is intentionally not a personal setup clone. It gives a ladder and
an interview flow that help a user create their own workspace, `AGENTS.md`,
rules, memory habits, delegation patterns, and delivery pipeline.

## Entry Point

Use the bootstrap command/skill:

```bash
/setup-my-context
```

It guides the user through L0-L4:

- L0: workspace
- L1: project context
- L2: memory from feedback
- L3: delegation
- L4: delivery pipeline

Non-technical users can stop at L2. Technical users can continue through L4.
